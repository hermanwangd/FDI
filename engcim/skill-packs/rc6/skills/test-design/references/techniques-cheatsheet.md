# 測試技法速查（Equivalence / Boundary / State / Scenario）

## 等價類劃分（Equivalence Partitioning）

- 把輸入域切成「系統行為相同」的類；每類取一代表值即可。
- 必切：有效類 ≥1＋無效類 ≥1（型別錯、空值、超範圍、格式錯各算獨立類）。
- 訊號：「輸入很多種但處理邏輯一樣」→ 用等價類，不要窮舉。
- 例：年齡欄位 18–65 → 類別 {<18, 18–65, >65, 非數字, 空}。

## 邊界值分析（Boundary Value Analysis）

- 缺陷聚集在邊界：對每個邊界取 min-1 / min / min+1 / max-1 / max / max+1（型別允許時）。
- 常見邊界：數值範圍、字串／清單長度（0、1、上限、上限+1）、日期（起訖日、閏年、時區交界）、
  容量（滿、滿+1）、分頁（第 0 頁、最後一頁、超出頁）。
- 訊號：規格出現「最多／至少／介於／不超過」→ 必有邊界值案例。
- 搭配等價類：先切類，再對有邊界的類補邊界點。

## 狀態轉移測試（State Transition）

- 對象有生命週期（訂單、工單、訂閱、issue）→ 畫狀態圖再設計。
- 覆蓋規則：每條**合法**轉移 ≥1 案例；每條**非法**轉移（如 cancelled→in_progress）都要有案例驗證被拒。
- 別忘：初始狀態進入、終態不可再轉、並發轉移（兩個操作競態）。

## 場景測試（Scenario Testing）

- 用 user story／端到端流程串多個功能：主流程（happy path）＋替代流程＋異常流程各 ≥1。
- 來源：驗收條件、PRD 的 Scenario 條目（pk-semantics）、S07 影響報告的傳導路徑。
- 場景案例同時是 smoke 集候選。

## 選用決策（30 秒版）

```text
輸入域大？      → 等價類
規格有範圍詞？  → + 邊界值
對象有狀態？    → + 狀態轉移（含非法轉移）
跨功能流程？    → + 場景測試
全部適用全用；不用的寫進測試計畫「不覆蓋說明」。
```
