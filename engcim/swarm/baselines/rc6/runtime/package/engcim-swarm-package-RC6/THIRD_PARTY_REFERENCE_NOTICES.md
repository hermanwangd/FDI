# Third-Party Design References

RC6 contains original ENGCIM skill implementations. No upstream source-code package is vendored by this bundle.

The following open-source/public skill projects were used as design references for workflow concepts:

- gstack — https://github.com/garrytan/gstack
- Superpowers — https://github.com/obra/superpowers
- GitHub Spec Kit — https://github.com/github/spec-kit
- BMAD Test Engineering Architect (TEA) — https://github.com/bmad-code-org/bmad-method-test-architecture-enterprise
- Anthropic Skills — https://github.com/anthropics/skills
- OpenHands Extensions — https://github.com/OpenHands/extensions
- SWE-agent ACI design — https://github.com/SWE-agent/SWE-agent

Before directly copying or vendoring upstream code/assets, review and comply with the corresponding upstream license. RC6 intentionally reimplements the required concepts in ENGCIM-native workflows instead of copying upstream implementations.
