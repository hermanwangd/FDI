# Workflow — Develop Feature

```text
Authenticated Human Feature Signal
        ↓
FT-T1 Intention
        ↓ intention.md / INTENTION_READY|BLOCKED
FT-T2 Delivery Spec
        ├─ governed Product Intelligence
        ├─ bounded Structural Intelligence
        └─ HERM-211 helper closure
        ↓ current feature-specific Evidence
        ↓ spec.md / SPEC_READY|BLOCKED
FT-T3 Implementation
        ↓ implementation.md + exact candidates / CHANGE_SET_READY|BLOCKED
FT-T4 Correctness
        ↓ correctness.md / PASS|FAIL|INCONCLUSIVE
```

Product/Structural intelligence can orient, constrain, prioritize and generate candidates. Current feature-specific pinned Evidence establishes current Change Surface truth. No Layer 1 gate by itself grants merge/deploy/release authorization.
