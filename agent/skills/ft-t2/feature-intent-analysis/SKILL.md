# Skill — feature-intent-analysis

**Purpose:** project the exact active `intention.md` into `IntentSpec` for FT-T2 helper execution without replacing T1 authority.

**Inputs:** exact active `intention.md` (`INTENTION_READY`, `ACTIVE`); bounded applicable Context when useful.

**Procedure:** pin Intention revision; faithfully extract objective/criteria/constraints/non-goals/non-exhaustive seeds; preserve stable IDs and blocking classification; record Context refs and unresolved ambiguity.

**Output:** `IntentSpec`.

**Must not:** consume raw Human Signal as canonical substitute; rewrite desired outcome/scope/criteria; choose final repositories; invent implementation design; hide ambiguity.
