# Skill — closure-review

**Purpose:** independently challenge a proposed ClosurePackage for false closure.

**Inputs:** exact active Intention, exact ClosurePackage, visible evidence/context permitted to reviewer; fresh independent evaluation context.

**Procedure:** challenge candidate recall, Change Surface evidence, dependency coverage, ownership/interface gaps, unsupported current claims, closure boundary and unknowns; deliberately search for missing repositories/surfaces; ensure all closure-critical claims are source/evidence backed.

**Output:** `ClosureReview` with exactly one of `ACCEPT_CLOSED_WITHIN_DECLARED_SCOPE|REOPEN|NEEDS_MORE_EVIDENCE`.

**Must not:** inherit hidden investigator reasoning as authority; repair candidate evidence; optimize for acceptance; translate accepted helper closure directly into `SPEC_READY`.
