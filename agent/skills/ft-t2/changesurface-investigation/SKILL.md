# Skill — changesurface-investigation

**Purpose:** investigate each material candidate and establish evidence-backed feature-specific repository/surface disposition.

**Inputs:** exact Intention, `CandidateRepoSet`, bounded Context, current source/runtime capabilities.

**Procedure:** pin current repo/source revisions; investigate modules/packages/APIs/classes/functions/events/schemas/config/tests/deploy/data; gather `EvidenceRecord`s; map findings to criteria/requirements; resolve ownership where possible; classify each repo `CANDIDATE|CONFIRMED|EXCLUDED|UNRESOLVED` and assign legal `required_action`.

**Output:** `ChangeSurfaceSet` + `EvidenceRecord`s.

**Must not:** use Context/history/graph alone to confirm/exclude; fabricate evidence; auto-promote newly found source changes into approved T3 scope without T2 contract update.
