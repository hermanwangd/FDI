# FV-003 sealed defect

Given a chart configuration with a missing or invalid `limits.ucl` or
`limits.lcl`, the candidate must reject the configuration with
`INVALID_CHART_CONFIGURATION` and must not render the chart as valid.

The frozen Product behavior is `chartLimits().max = 10`. The downstream
fixture baseline intentionally contains `chartLimits().max = 1000` before S05
r1. This verifier input is evaluator-only and is not supplied to the S05
producer as a diagnostic claim or exact correction.
