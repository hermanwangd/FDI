# Synthetic acceptance

Four hand-authored bundles cover every dimension. Exact: all dimensions MATCH, INELIGIBLE. Different: all UNKNOWN, NOT_PROVEN_INDEPENDENT. Near: text dimensions UNKNOWN with a near-duplicate review signal; identity and lineage remain UNKNOWN. Empty: UNKNOWN, never a match. Every bundle runs twice from packaged CLI, with identical output bytes and selectionAuthorized=false.

These checks test detection and safe abstention, not formal repository independence. No new external corpus or candidate repository is inspected. H0/H1 remain pinned to709 and their content-addressed binary; the comparator receives its own source/runtime digest and must not replace that binary.
