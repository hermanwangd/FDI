# Workflow — Bootstrap Product

```text
Product source inventory + docs + history
        ↓ exact source acquisition / pins
PA-03 repository inventory bootstrap
        ↓
Structural Intelligence indexing / observations
        ↓
PA-05 historical delivery reconstruction
        ↓
Product Semantics / Realization proposals where authorized
        ↓
Product Team review / publication policy
        ↓
PUBLISHED + ACTIVE Product Assets
        ↓
derived Registry
        ↓
onboarding readiness
```

Bootstrap generates proposals; it does not silently publish semantic truth. Full bootstrap happens once per Product scope, followed by incremental maintenance.
