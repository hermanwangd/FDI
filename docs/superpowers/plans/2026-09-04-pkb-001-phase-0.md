# PKB-001 Phase 0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a fail-closed readiness, acquisition, isolation, and evaluation harness that can authorize PKB-001 arm execution only after every prerequisite in the candidate specification is evidenced.

**Architecture:** Python validation tooling consumes strict JSON records under `validation/pkb001/` and produces no Product truth. One readiness gate verifies external authority and live-provider evidence; an acquisition validator pins immutable inputs; an isolated runner enforces arm allowlists; and a deterministic evaluator computes frozen metrics. The harness reports `BLOCKED` until authentic rc9, Graphify evidence, Skill availability, and a calibration snapshot are supplied.

**Tech Stack:** Python 3 standard library, JSON Schema 2020-12 documents, pytest, existing Java 17/Spring Boot runtime as an external dependency, deterministic release tooling.

## External approval checkpoints

The harness can be implemented without external evidence, but it cannot become `READY` until all of these are separately reviewed: authentic rc9 bytes and governance lock, live Graphify attestation, approved/materialized PK-S1 and PK-S2, pinned calibration repository and history source, sealed gold-set digest, frozen metric protocol, and resource/security policy. Receipt of those inputs authorizes validation only; it does not authorize Product publication or DEV-204/F001 execution.

## Acceptance and rollback

Phase 0 implementation is accepted when negative tests prove every missing or unsafe prerequisite blocks, isolation tests prove prohibited inputs cannot cross arm boundaries, evaluation tests reproduce exact metrics, the repository's current result remains honestly `BLOCKED`, and all repository checks pass. Roll back by reverting focused commits in reverse order; preserve any externally supplied authority or evidence for separate governance disposition rather than deleting it.
